Predicción de Defaults de Préstamos

Clasificación balanceada con SMOTE para datos desbalanceados

← Volver

Problema

En datos de préstamos altamente desbalanceados, ¿cómo predecir con precisión cuáles clientes entrarán en default sin sacrificar la detección de casos positivos? ¿Cómo manejar el desbalance de clases inherente al problema?

Metodología

Pipeline de clasificación balanceada para predicción de default de préstamos con manejo de desbalance de clases:

  • Análisis del desbalance de clases (típicamente 80-90% sin default)
  • Aplicación de SMOTE (Synthetic Minority Over-sampling Technique) en el pipeline
  • Normalización de features con StandardScaler dentro del pipeline
  • GridSearchCV para optimización automática de hiperparámetros
  • Evaluación con Precision, Recall, F1, ROC-AUC en validación cruzada

Resultados Principales

  • SMOTE aumentó recall de default de 45% a 78% en modelos sin balanceo
  • Random Forest con SMOTE logró F1-Score 0.74 en validación cruzada
  • ROC-AUC mejoró de 0.78 a 0.85 con optimización de hiperparámetros
  • Balance Precision-Recall: Precision 0.68, Recall 0.80 en test set
