Análisis y Clustering de Jugadores de Fútbol

Segmentación de jugadores por habilidades y características

← Volver

Descripción

Este proyecto realiza un análisis exploratorio, visual y no supervisado de una completa base de datos de jugadores de fútbol. El objetivo es aplicar técnicas de normalización, clustering y proyección dimensional para identificar grupos de jugadores con habilidades equivalentes y patrones similares de desempeño.

Metodología

  • Análisis Exploratorio de Datos (EDA)
  • Normalización y escalado de características
  • Algoritmos de clustering: K-means, DBSCAN, Hierarchical
  • Proyección dimensional: PCA, t-SNE
  • Visualización interactiva de clusters

Características Analizadas

  • Atributos físicos: altura, peso, velocidad
  • Habilidades técnicas: precisión de pase, regate, tiro
  • Estadísticas de juego: goles, asistencias, apariciones
  • Posición en el campo

Resultados

El análisis identificó aproximadamente 5-7 clusters principales correspondientes a diferentes posiciones y perfiles de jugadores: delanteros, centrocampistas, defensas, y porteros. Cada cluster muestra patrones distintivos de habilidades que permiten identificar jugadores con roles similares en el campo.

Tecnologías Utilizadas

  • Python, Pandas, NumPy
  • Scikit-learn (K-means, DBSCAN, PCA)
  • TSNE (Manifold Learning)
  • Matplotlib, Seaborn, Plotly
