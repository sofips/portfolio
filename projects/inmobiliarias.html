Predicción de Precios de Viviendas en California

Modelado de regresión a partir de datos del censo

← Volver

Descripción

Este proyecto presenta un análisis exploratorio exhaustivo y modelado de regresión para predecir precios de viviendas en California. Utilizando datos del censo de 1990, se incorporan características geográficas y demográficas con visualización interactiva de relaciones entre variables, selección estratégica de características, y comparación sistemática de algoritmos de regresión.

Dataset

El conjunto de datos contiene 20,640 registros de propiedades de California del censo de 1990, con variables como:

  • Latitud y Longitud
  • Edad promedio de las viviendas
  • Número total de cuartos
  • Población
  • Ingresos promedio del hogar (variable objetivo)

Metodología

  • Análisis Exploratorio de Datos (EDA) detallado
  • Visualización de distribuciones y correlaciones
  • Detección y tratamiento de outliers
  • Normalización y escalado de características
  • Análisis de correlación y multicolinealidad
  • Selección de características (feature selection)
  • Entrenamiento de múltiples modelos de regresión
  • Validación cruzada y evaluación

Modelos Evaluados

  • Linear Regression
  • Polynomial Regression
  • Ridge Regression (L2 regularization)
  • Lasso Regression (L1 regularization)
  • Random Forest Regression
  • Gradient Boosting Regression

Métricas de Evaluación

  • Mean Absolute Error (MAE)
  • Mean Squared Error (MSE)
  • Root Mean Squared Error (RMSE)
  • R² (Coeficiente de Determinación)

Resultados

Los modelos basados en ensambles (Random Forest y Gradient Boosting) alcanzaron el mejor desempeño predictivo, con un R² superior a 0.85. Las características geográficas (latitud y longitud) junto con el tamaño promedio de las viviendas resultaron ser los predictores más importantes.

Tecnologías Utilizadas

  • Python, Pandas, NumPy
  • Scikit-learn (Regresores)
  • Matplotlib, Seaborn, Folium (Geolocalización)
  • Plotly (Visualización interactiva)
