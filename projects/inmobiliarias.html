Predicción de Precios Inmobiliarios California

Regresión multivariable con técnicas de machine learning

Problema

¿Cómo predecir el precio de una vivienda en California usando características como ubicación, cantidad de habitaciones, ingresos medios del área y ocupancia? ¿Qué modelo de regresión ofrece el mejor balance entre sesgo y varianza?

Metodología

Pipeline de regresión para predicción de precios de viviendas en California usando dataset de censo 1990:

  • EDA con 8 características: Latitud, Longitud, Edad vivienda, Total cuartos, Total dormitorios, Población, Ocupancia, Ingresos
  • Filtrado de outliers por percentiles (Q1/Q95) para mejorar robustez
  • Normalización con StandardScaler y selección de features relevantes
  • Entrenamiento de múltiples modelos: Linear, Ridge, Lasso, Random Forest, Gradient Boosting
  • Evaluación con MSE, RMSE, MAE, R² y análisis de residuos

Resultados Principales

  • Random Forest y Gradient Boosting lograron R² > 0.87 en test set
  • RMSE < $69,000 (mejora vs baseline de $90,000)
  • Features más importantes: Longitud, Latitud, Edad vivienda, Ingresos
  • Modelos capturan bien relaciones no-lineales geoespaciales y temporales
